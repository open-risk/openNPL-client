# openNPL-client

![openNPL Logo](opennpl-logo.png) 

This repository collects client software for the openNPL database. 

## About openNPL

**openNPL** is an open source platform for the management of credit portfolio data with a particular focus on non-performing loans. openNPL implements and builds on the detailed European Banking Authority loan templates for NPL data and the US Fannie Mae / Data Dynamics schemas. It thereby enables the collection and easy management of loan data according to best-practices.

### Code and User Documentation

* Technical documentation is included in [openNPL distribution](https://github.com/open-risk/openNPL) and is hosted online at [readthedocs](https://opennpl.readthedocs.io/en/latest/)
* User documentation is available [here](https://www.openriskmanagement.com/documentation/opennpl/)

### Domain Knowledge and Data Schemas

The domain knowledge and detailed data documentation is provided via the **Open Risk Manual**. The following links are good starting points:

* [NPL Concepts](https://www.openriskmanual.org/wiki/Category:NPL)
* [EBA NPL Templates](https://www.openriskmanual.org/wiki/EBA_NPL_Template)
* [FM SFLP Templates](https://www.openriskmanual.org/wiki/FM_SFLP_Template)

The Open Risk Manual articles further connect specific NPL knowledge bases to more general *credit portfolio* and *risk management* concepts, procedures and overall knowledge bases.

> To use the clients you obviously need to have at least one openNPL instance running!

## openNPL Clients

### Curl

Simple curl based clients for interrogating the OpenNPL API

### Python Client

Python clients aims primarily to support extracting / loading data into openNPL, e.g., from the EBA spreadsheet files etc.


## OpenAPI

Autogenerated openapi client from the django swagger schema
